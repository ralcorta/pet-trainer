# Pet Trainer

PWA para seguimiento de clases de entrenamiento canino. Datos locales (IndexedDB / Dexie), exportables en CSV.

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Sitio

Publicado en GitHub Pages: https://ralcorta.github.io/pet-trainer/

## Respaldo

Desde Inicio o Fichas podés descargar un ZIP con CSV (+ `backup.json`) e importarlo en otro dispositivo.
